# v1.2.1 title, pause and arena music

Upload all contents to your GitHub repository root, keeping the folder structure.
This includes the earlier controller, credit and arena MP3 updates.
Add MP3s directly inside public/music/title/, public/music/pause/, or the arena folders.
Commit and let Render rebuild. Keep Settings > Music selection set to Auto.
Empty folders use generated music. Multiple MP3s play in filename order and loop.
No code changes or track list edits are required when adding MP3 files.
Check Settings for v1.2.1 after deployment.
See public/music/README.md for all folder names.
