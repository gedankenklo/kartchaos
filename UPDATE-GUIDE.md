# v1.52.1 - Player tile spacing

Requires v1.52.0. Extract and upload the contents at the GitHub repository root, preserving folders. Merge/overwrite, commit and let Render rebuild. Refresh the game afterwards.

Multiplayer driver cards have more space between tiles and consistent inner padding. Portraits sit above the full-width names, with player badges in the upper left. Names such as Mango and Peach no longer crowd the edge. Compact-height screens use smaller portraits. All controls and game functionality are retained.

Verified in the browser with three local players, including Mango; production build passed. No MP3s or music manifest included.
